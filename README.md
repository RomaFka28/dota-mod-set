# Dota Mod Set

Локальное Windows-приложение для организации косметических VPK/ZIP-наборов Dota 2.

## Требования

- Windows, установленная Dota 2 (путь задаётся в ⚙ Настройках).
- Мастерская эффектов дополнительно требует (проверяется при открытии, видно в статусе):
  - **.NET 8 Runtime** — нужен для VRF Decompiler: https://dotnet.microsoft.com/download/dotnet/8.0
  - **Dota 2 Workshop Tools DLC (~2 ГБ)** — нужен для компиляции `.vpcf → .vpcf_c`
    (игра читает только `.vpcf_c`): Steam → Библиотека → вкладка «Инструменты» →
    Dota 2 Workshop Tools Alpha, страница DLC: https://store.steampowered.com/app/313250/ .
    Без DLC мастерская может только искать и извлекать частицы — кнопка
    «Сгенерировать VPK» заблокирована.
  - Сам VRF Decompiler (~55 МБ) скачивается кнопкой из мастерской автоматически.
  - Права на запись в папку игры (для батч-компиляции через `content/dota_addons`);
    если Dota в Program Files — запускайте приложение от имени администратора.

## Запуск

```powershell
npm install
npm start
```

По умолчанию путь к Dota 2: `D:\SteamLibrary\steamapps\common\dota 2 beta`.

## Границы безопасности

- Приложение не использует инъекции, не запускает игру и не изменяет `pak01`.
- Набор разворачивается только в собственную папку `Dota2CosmeticMods\\sets` рядом с игрой.
- При установке готового набора VPK копируются во все найденные языковые папки Dota (`dota_russian`, `dota_english` и т. д.).
- Перед изменением файлы целиком готовятся во временной папке; затем создаётся новый уникальный набор и манифест.
- Откат удаляет только файлы, перечисленные в манифесте, если их хэш всё ещё совпадает. Чужие или изменённые файлы остаются нетронутыми.
- ZIP принимаются в кэш; если внутри есть VPK, Windows `Expand-Archive` извлекает их во временную папку. Внешний VPK-инструмент не поставляется и не требуется для готовых VPK.
- Перед распаковкой ZIP проверяются пути, символические ссылки, число файлов и максимальный размер распакованных данных.
- Инструмент VRF скачивается из зафиксированного релиза и проверяется по SHA-256 перед распаковкой.
- При закрытии приложений перед установкой используются конкретные PID найденных процессов, а не глобальное завершение всех процессов с одинаковым именем.

Файлы из изолированной папки не подключаются к Dota автоматически: это намеренно — приложение не меняет базовые игровые архивы и не внедряется в процесс игры. Используйте только с законной, поддерживаемой вашей конфигурацией запуска игрой.
